## 关键源码细节（Pindo，读自 lib/engine/）

- `downscaler.ts`：注释明写 "sRGB → gamma decode → linear RGB area average → gamma encode → sRGB"；`'edge-aware'` 模式按亮度梯度找边界格，边缘色占比 ≥0.55 且更暗 18 luma 时吸附过去（与我们"先配后投"同类思路）；`'dominant'` 模式 6-bit 桶众数取桶均值。
- `color-matcher.ts`：CIELAB（D65）+ 简化 CIEDE2000，逐像素独立匹配，无区域一致性。
- `dithering.ts`：只实现了 Floyd-Steinberg（**RGB 空间**扩散误差、raster 扫描无蛇形），ordered 是占位符。—— 我们的 Lab 空间 FS 更讲究。

## 业界收敛的共识（5 条）

1. **感知色彩空间 + CIEDE2000 是绝对标配**（所查 6+ 项目全部）。
2. **降采样带线性光 gamma 校正**，且普遍提供"边缘/众数"式格子取色消灭边界混合色。
3. **黑白锚点 + 色板原色保真**：纯白格锚白色豆，不让奶白/象牙白抢走。
4. **场景化策略**（卡通 vs 照片 vs 图标）是进阶分水岭。
5. FS 抖动最常见；区域一致性/小碎色清理做后处理。

## 我们领先的地方（不需要动）

- **U²-Net 主体分割去背景**（ML+颜色统计交叉校验+细结构救援）——开源圈几乎没人做到这个深度。
- **Lab 空间 FS 抖动**（对标项目多在 RGB 空间扩散）。
- 三风格（写实/抽象 k-means/线稿 Sobel）、品牌色号表齐全、k-means 亮度分位确定性初始化。

## 我们的差距（全部对上 01/02 的实测）

1. 线性光降采样（Pindo 明确做了；我们伽马空间均值，实测 -4.3 L*）
2. 边缘感知/投票式取色（业界普遍；我们默认盒平均，实测杂色 58~140 颗）
3. CIEDE2000 默认开（行业标配；我们默认关）
4. 黑白锚点（bead-grid-studio 有；我们纯白可能被奶白抢走）
5. 自动增强预设（beadmachine 滤镜组；我们默认全 0、无锐化）

## 结论

算法骨架正经且多项领先开源圈，缺口集中在"默认设置"和两处细节（伽马均值、边界取色），**全部是增量修改、不需重写**。实施路线见 [README.md](README.md)（六步：先配后投 → CIEDE2000 默认 → 黑白锚点 → 保留 Lab FS ±蛇形 → 抽象/掩码改线性光 → 可选一键增强）。
