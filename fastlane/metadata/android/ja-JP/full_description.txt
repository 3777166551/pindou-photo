どんな写真もアイロンビーズの図案に変える、完全オフラインの Android ツール。ペットの写真、イラスト、アバターから、作業用チャートとビーズの購入リストを生成します。ビーズ愛好家のために作られたキャンデルステッカー風 UI。

✨ 主な機能
• 写真 → 図案:24/48/90/120 色の汎用パレット、Artkal / MARD / Perler / Hama / Nabbi の公式カラーコード対応
• リアル / 抽象 / 線画の 3 スタイル、k-means 減色 + Floyd–Steinberg ディザ、丸板対応
• 品質モード:輪郭クリア / ノイズ除去 / 精密配色(CIEDE2000)、色数制限マージ(12/18/26/40 色)
• 端末内で背景除去(U²-Net モデル内蔵、通信なし)、ウォーターマーク除去、完成品写真からの図案復元
• 古い図案を撮影して自動グリッド認識、PDF 図案の取り込みにも対応
• 内蔵テンプレート:8 カテゴリ 277 種(Fluent Emoji ベース、MIT)
• ビーズリスト:数量・比率・重量・コスト、パック換算(約 N パック/1000 個)、在庫管理と代替提案
• 刺繍サポート:色ごとの位置取り、タップ/スワイプ塗り、板/行ガイド、チェックインカレンダー、画面常時点灯
• 3D プレビューと多層スタック合成(リスト統合)
• 投影アライメント:4 点キャリブレーションで現在の色を実際のピンボードに固定
• AR 体感、クロスステッチ書き出し(DMC 454 色)、GIF 書き出し、完全バックアップ/復元

🔒 プライバシー:ネットワーク権限を要求しません。通信なし、アップロードなし、広告なし、トラッキングなし。
