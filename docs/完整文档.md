# 照片变拼豆(PindouPhoto)

一个安卓手机 APP:把照片一键变成**拼豆(熨斗豆/Perler Beads)图纸**,自动匹配豆豆颜色、统计用量、导出可打印的高清图纸。纯原生开发,零第三方框架、**零网络权限——全功能离线,不上传任何数据**;界面为柔焦粉彩玻璃拟态风(pastel glassmorphism)。

### 写实 vs 抽象怎么选

- **写实**:每格豆单独对应照片像素并匹配色板,细节最多,适合人像、宠物等需要还原的照片
- **抽象**:先把照片缩小到"砖块"粒度(双线性缩放完成邻域平均),一整块区域共用一种豆色,
  再叠加 k 均值限定主色调——出来的效果就像乐高马赛克:大色块、扁平配色、远看轮廓清晰。
  抽象程度四档可选(2×2/3×3/4×4/6×6),越大越粗犷越好拼;
  「限定主色调」开启时还能选择提取几种主色、是否吸附到真实豆色(照单买豆)
- **卡通 / 二次元 / 3D 等风格**:用免费 AI 工具生成二次元图,回本 APP 去水印后进拼豆流水线
  观感比程序滤镜好一个档次(v1.8 起已移除本地的卡通描线 / 动漫网点滤镜)

### 想要二次元/动漫风图纸

用「即梦」「豆包」等免费 AI 工具(或 PC 开源软件)把照片变成二次元,保存到相册;
回本 APP 导入后,点「照片预处理 → 🩹 去水印」,拖框盖住水印 → 「修复」,
再正常生成图纸。v2.26 起本 APP 已移除云端 AI 调用,全离线零费用。
本地 AnimeGAN 模型与云端 Seedream 均已移除(历史调研见 docs/)。
### 去水印怎么用

编辑页「照片预处理」点「🩹 去水印」:弹窗里在图上**拖一个框盖住水印** → 点「修复」。
算法自动识别框内的水印笔画(与框外环带背景比对),只修复水印处,背景纹理、
结构边缘原样保留;框错位置或框内只有噪点时会自动跳过不误伤;多个水印逐个框即可。
纯本地算法、毫秒级、不上传任何数据。
回归测试:`tools\bgtest\wm\WatermarkSuite.java`,96 组合
(5 背景 × 5 水印类型 × 3 位置 × 框选松紧 × 边界情况 × 真实照片),
修复区平均 PSNR 21.4 → 46.0 dB,接触表输出 `out_wm2\`。

### 一键去背景怎么用

编辑页「照片预处理」打开「一键去背景」后拖**容差滑杆**(0~100 连续调节)。
默认走 **U²-Net 小模型语义分割**(u2netp,Apache-2.0 开源,离线推理,
单次约 0.1~0.3 秒)。v2.4 起 pipeline 重构(v6),修复三个实测问题:

1. **先抠图后缩格**:旧版先把照片缩到拼豆网格再抠图,主体边缘格子被
   背景色污染,豆色匹配后描边发灰、轮廓颜色失真。新版先在高分辨率上
   抠图,格子颜色只平均掩码内的像素,边界颜色不再被冲淡;
2. **容差对 ML 生效**:旧版容差滑杆只作用于颜色统计兜底,ML 路径固定
   阈值,调了没反应。新版容差直接映射 ML 概率阈值(右 = 抠更多);
3. **掩码错位/漏抠守卫**:旧版对非方形画幅掩码错位(两侧背景抠不掉),
   满幅特写漏抠成小碎片时守卫拦不住。新版整幅拉伸逐点对应 +
   「ML 前景占比远小于颜色统计前景占比即判定掩码塌缩」交叉校验,
   猫脸/人像/篮球等灾难场景自动改用兜底,不会毁图;
4. **细结构救援**:太阳光芒、漂浮装饰这类"与主体分离的细小部件"是
   SOD 模型通病——实测 u2netp 和 168MB 的 u2net 完整版概率图里都是
   ≈0,任何阈值都救不回。新版用「边界背景聚类 → 双门槛颜色泛洪」
   找出背景连通域,泛洪前景中与背景色明显不同(ΔE>16)、面积不超限的
   孤立部件并入掩码;纯色背景插画的光芒/飘带完整保留,复杂照片语料
   回归无劣化。

- **往右调 = 主体圈得更小**,背景抠得更干净;**往左调 = 保得更多**
- 白兔/白衣这类与背景颜色接近的主体也能整块保住;白云、阴影、水印一起清掉
- 满幅特写(画面里没有背景)会自动放弃,不会为抠图而毁图
- 个别格子不满意?开「画笔模式」用橡皮擦掉、或点格修恢复即可
- 后台批量测试环境见 `tools/bgtest`(桌面 JVM 直跑算法,不依赖手机;
  `Compare.java` 新旧管线对比、`TestAspect.java` 非方形画幅专项)

### 与市面主流拼豆 APP 的对比

已具备主流核心功能:照片导入、多档色板、两种本地风格 + AI 风格化、符号图纸、坐标、
用量统计、导出打印(PNG/PDF)、文字图案、品牌色号近似对照、一键去背景、手动修格、
**滑动画笔手绘、空白画布开新图纸、内置模板库、镜像/旋转变换、项目存档与多项目管理**。

## 📲 安装到手机

1. 用数据线 / QQ / 微信文件助手,把 `build_apk\PindouPhoto-v2.15.apk` 传到手机
2. 在手机上点开 APK,系统提示"未知来源应用"时选择**允许安装**(设置 → 安全 → 安装未知应用)
3. 装好后的名字叫「**照片变拼豆**」,橙色 3×3 豆豆图标

支持 Android 7.0(API 24)及以上,无需任何权限(Android 10+ 保存相册免权限)。

## 🔨 重新构建

本仓库自带一套免 Gradle 的构建链(在 `tools\` 目录,约 700MB,已安装好):

```bat
build_apk.bat        rem 输出 build_apk\PindouPhoto-v1.0.apk
```

构建需要本地自备 `tools\` 目录(仓库不含,含密钥与大型二进制):JDK17、Android build-tools 34.0.0 + platform android-34、ONNX Runtime Android AAR 解包到 `tools\ort_aar`(取 classes.jar 与 jni\arm64-v8a 下的 .so)。

签名密钥 `pindou.keystore` 不随仓库分发;口令从环境变量 `PINDOU_KS_PASS` 读取,别名 `pindou`,首次构建会自动生成测试签名。

│   ├── EffectRenderer.java       仿真圆豆效果图
│   └── PdfExporter.java          A4 多页 PDF 导出
└── util/
    ├── ImageLoader.java          采样解码 + EXIF 方向修正
    ├── GallerySaver.java         MediaStore 保存到相册
    ├── ProjectStore.java         项目存档(files/projects/*.json)管理
    ├── Jsons.java                存档 JSON / Base64 位图编解码

**核心流程**:照片 → 居中裁剪成画幅比例 → 双线性缩到 N×N → 亮度/对比度/饱和度调节 → 逐像素转 Lab → 在色板中找 ΔE 最小的颜色(可选 Floyd-Steinberg 误差扩散) → 生成图纸格 + 用量统计。

## 📖 拼豆知识速览(详见 APP 内"拼豆小知识")

- **豆子规格**:标准豆 5mm(每格约 0.5cm,29×29 板成品约 15×15cm)、迷你豆 2.6mm(更精细但费眼);两种孔距不同,不能混用
- **模板**:标准方板 29×29 孔,可拼板扩幅(58²=4块、87²=9块、116²=16块);另有圆形/六边形等异形板
- **色数选择**:24 色适合 emoji/卡通,48~60 色适合一般图案,90 色以上适合人像/风景
- **品牌**:Perler(美)、Hama(丹麦)、Artkal、漫德、伊诺思等,色号体系各不相同——本 APP 颜色是通用参考值,拼时以实物豆为准
- **熨烫**:垫熨烫纸,中温无蒸汽,每面 10~20 秒,完全冷却再揭纸,两面都烫更结实

## ⚠️ 说明

- 色板颜色是按常见拼豆色系整理的参考色,不同品牌/批次的实物豆会有差异
- 首次为个人自用开发,测试签名安装时如遇"风险提示"属正常现象
- 图片仅在本地处理,不上传任何服务器
