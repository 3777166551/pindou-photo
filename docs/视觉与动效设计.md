## ★ 现行方案(v2.39):糖果贴纸风(Candy Sticker)

**为什么改**:v2.25 的低对比玻璃拟态(白 92% 磨砂卡+浅灰描边)在奶油底上
糊成一片,层次弱、没有记忆点;框选类控件(CropView/去水印框)还是纯功能件
(橙细线框/绿矩形),用户装机验收反馈"界面和框选真的很不好看"。

**调研结论**(2026-09-07,Dribbble pixel-art-app / photo-crop-app 案例走查 +
小红书拼豆圈审美,详见 ROADMAP v2.39 条目):
- 图片编辑器框选的当行语言 = **圆角挖孔压暗 + L 形圆头角标 + 三分线 +
  尺寸徽章 + 角点拖拽改大小**(iOS 相册/Google Photos/醒图一派);
- 手作/少女向工具 APP 的潮流 = **贴纸化 neubrutalism**:奶油底、
  厚墨描边、硬投影、糖果色图标盘、贴纸微旋转(小红书手账/贴纸墙同款);
- 拼豆圈关键词不变:多巴胺点缀、手作感、像素/拼板母题(第一章调研仍有效)。

### 开屏动画 v2.39「贴纸拍击」(重做)

取代 v2.18 的"豆雨落下"版(SplashActivity 整体重写,仍纯 Canvas 零依赖,
约 1.6s,点击跳过,种子固定 42 保证每次摆设一致):
1. **豆雨从四面八方飞入**(620ms):每颗豆独立随机起角/距离/延迟,带微弧线
   收拢进拼板,落位瞬间 squash 回弹——比旧版"只从天上掉"更活泼;
2. **贴纸 logo 拍下**(340ms,Overshoot 2.2):白底墨描边圆角贴纸卡
   (与首页贴纸卡同语言)从 1.9x 拍到 1x,旋转 -14°→-4°,过冲瞬间轻微压扁回弹;
3. **冲击特效**(与高光并行):黄油色冲击环从贴纸中心扩散,
   14 颗糖果纸屑按随机角度迸开并微下坠淡出;
4. **高光斜扫**(340ms):45° 白色渐变带扫过贴纸(裁剪在卡身内);
5. 停 360ms 淡入主界面。
改花样:SplashActivity.java 一个文件,时长在 startShow,贴纸样式在 drawSticker。
注意:fxT 必须直接取动画进度(自增在 60fps 下走不满,特效会停在半路)。

### 注意

- 拼豆图案内部的像素色(如水豚棕 8D6E63)是数据不是 UI 色,别顺手改掉;
- PatternView 图纸画布的坐标数字保持工程感,不参与贴纸风;
- 动效系统(Anim.pressScale/expand/collapse/pulse)不变,继续用。

## 一、历史:拼豆圈审美调研(手绘风时期)

**用户画像**:拼豆圈主力是小红书上的 15~30 岁女性玩家,玩法是手作挂件
(包挂/钥匙扣/房间装饰),流行 IP 是卡皮巴拉、Chiikawa、Loopy 这类 kawaii 形象
(注意:IP 形象有版权,只能做"神似原创")。

**审美关键词**(从小红书拼豆tag的高赞内容归纳):

| 关键词 | 含义 | 落点 |
|---|---|---|
| 氛围感手作 | 奶油色/暖色底,手写文字,贴纸拼贴 | 配色与字体 |
| 贴纸感 | 描边 + 硬投影(offset shadow),不是糊糊软阴影 | 按钮/卡片 |
| 像素/拼板母题 | 拼豆本身就是像素艺术,底板孔洞是身份符号 | APP 背景 |
| 多巴胺点缀 | 少量高饱和点缀色(薄荷绿/柠檬黄) | 进度条/辅助色 |
| 海报感大字 | 综艺字幕式斜体大标题 | 得意黑标题 |

**结论**:风格 = kawaii 手作(站酷快乐体正文)× 潮流海报(得意黑标题)
× 拼豆底板母题(点阵背景)× 贴纸描边硬投影(按钮卡片)。

`PatternView` 画布里的坐标数字不是 TextView,不受影响(这是对的,

## 五、开屏拼豆动画(v2.18)

`SplashActivity.java`(已注册为 LAUNCHER 入口,`SplashTheme` 同底色防闪白)。
纯 Canvas + ValueAnimator,零依赖,约 1.7s,点任意处跳过:

1. **领头豆弹跳落下**(0~0.52s,BounceInterpolator):一颗珊瑚橘豆从屏外掉进拼板,
   带厚度描边 + 镜面高光;
2. **豆雨落位**(0.76s):其余 34 颗按固定伪随机延迟依次从上方落进各自的孔,
   落位瞬间做 **squash & stretch**(压扁 12% 再回弹)——动画十二法则里
   最出"3D 感"的手法,配合 overshoot 弹性曲线就是"Q 弹 3D";
3. **果冻抖动**:全板轻微 squash 抖三下,得意黑 logo「照片变拼豆」pop 弹出;
4. 停留 0.5s 淡入主界面。

**为什么不是二次元立绘/真 3D**:立绘要美术资源(版权+体积+审美不可控),
真 3D(OpenGL/Unity)对零依赖纯 Java 工程是架构级负担;弹跳+squash&stretch
+高光描边这套 2D 动画语法在视觉上就是"3D 感"的行业标准做法,
1.7 秒内传达的是"品牌=拼豆+快乐",信息密度刚好。

**后续想换花样**:改 `PegBoardView.onDraw` 一个文件即可,颜色在
`BEAD_COLORS`,行列数 COLS/ROWS,落位节奏在 delays。

## 五点五、微动效系统(v2.20)

`util/Anim.java`,四个原语,全部 View.animate() 实现、时长 ≤200ms:

| 原语 | 效果 | 应用位置 |
|---|---|---|
| `pressScale` | 按下缩到 0.95、松手 overshoot 弹回 | 主页 7 个大按钮;编辑页 3 个 tab、风格/砖块/形状/限色 chips、AI 按钮、撤销重做、镜像旋转 |
| `expand` | 淡入 + 10dp 上滑(Decelerate) | 抽象面板、容差行、画笔面板、拼豆模式面板、"还原原始照片"按钮 |
| `collapse` | 淡出 + 8dp 下滑后 GONE | 上述面板的关闭 |
| `pulse` | alpha 0.45→1 快速呼吸 | tab 切换(图纸/效果图/豆单)内容区 |

页面切换过渡(res/anim/):进编辑器/知识页 = 新页从底部浮 8% 上来
(`enter_up`)+ 旧页轻微压暗(`exit_dim`);返回 = 反向(`enter_undim` +
`exit_down`,挂在 EditorActivity.finish() 上,系统返回键同样生效)。

设计原则:**动画只做反馈不做表演**——所有动效都在 220ms 内、单属性、
有物理隐喻(按=陷,展开=浮现,切换=呼吸),不阻塞交互、可以被打断。
列表项不做逐条 stagger(豆单刷新频繁,会闪)。
