4/4 PASS:行列数全对,逐格采样 ΔE≤1.1(标准/大格/细密/无网格线)。

### 真实图片(39 张,双模式:全图 / 内缩5%模拟粗框)
- **图纸类全对齐**:kd_14/15/16/19 等真实拼豆图纸的格距与相位
  与真实格线完全重合,采样结果图案完整、颜色准确(目检确认);
- **边缘背景裁剪生效**:kd_15 raw 32x33→裁后 21x22(黑底全去,

- **负样本正确拒绝**:5 张实物设备照中 3 张 FAIL(质量门拦截),
  不再产出垃圾网格;
- **已知局限**:
  1. 整页文档(含标题/图例)自动扫描不可靠(gh_110:竖线格距正确、
     横线被标题区干扰)——APP 里由用户框选网格区域规避;
  2. 格距 <4px 的小像素图(~192px 截图)低于检测下限,识别不稳定
     ——此类图本质是数字图纸,应走"直接按像素读取"路线(未做);
  3. 教程缩略图(100x100)非网格图,结果无意义,负样本同理。

## 迭代史(桌面合成测试抓出的 bug)

1. **自相关倍频陷阱**:26px 格距被识别成 78(3x 周期自相关更强)
   → 改为峰间距中位数为主估计,自相关降级为兜底;
2. **噪点伪峰**:±2 级噪点在投影里产生 4.5px 伪峰间距
   → 投影平滑 + 峰显著性(>0.6σ)+ minLag 非极大抑制;
3. **框选半格偏置**:框总比图纸大一圈,直接 round 多出一格
   → 格数估计扣掉半个 pitch;
4. **相位错半格**:首峰是"线"不是"格中心" → 统一首峰 + pitch/2;
5. **无质量门的假阳性**:实物照片被硬解出 36x112 垃圾网格
   → 峰间距一致性门(≥60% gap 是中位数的整数倍 ±18%);
6. **边缘背景假格子**:框进来的网站黑底形成整行/列假格子
   → 边缘背景裁剪(边主色一致率 ≥90% + 全图占比 ≥30% 才裁,
     防止误裁纯色边框图纸;每边最多裁 35%)。
