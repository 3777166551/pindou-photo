# 拼豆 App 设计合同（Design System Contract）

> 用法：任何 UI 任务开工前必须先通读本文件；一次任务只做一页；
> 完工后必须对照第 9 条逐项自查并报告结果。本文件是唯一视觉标准，
> 与现有实现冲突时以本文件为准，禁止自行发明新的视觉规则。

## 0. 产品与基调
- 产品：拼豆图纸工具 App。用户：手工爱好者（偏休闲女性用户）。
- 气质：温暖、可爱、有手作感；不要商务感、不要科技感。
- 视觉基调：淡紫马卡龙色系 + 拼豆底板点阵纹理，整体像"铺满豆子的软垫子"。
  紫色克制使用：只给主操作、选中态和关键强调，禁止大面积铺底。

## 1. 色板（token 化，禁止在布局里写死色值，禁止使用表外颜色）
| token | 亮色 | 深色 | 用途 |
|---|---|---|---|
| colorPrimary | #6750A4 | #D0BCFF | 主按钮、选中态、关键强调、链接 |
| colorPrimaryContainer | #EADDFF | #4F378B | 选中芯片底、主 CTA 卡片底 |
| colorBackground | #FAF7FD | #1C1B22 | 页面底层 |
| colorSurface | #F3EFF9 | #26232E | 卡片、弹窗底 |
| colorStroke | #E2D9F0 | #3A3547 | 卡片描边、分隔线 |
| textPrimary | #1D1B20 | #E6E1E9 | 标题、正文 |
| textSecondary | #6B6577 | #9A93A6 | 辅助说明 |
| colorSuccess | #2E9E6B | #6FCF9C | 完成、达标 |
| colorWarning | #E8A13D | #F0B35B | 提示、缺料预警 |
| colorDanger | #C62828 | #EF8A80 | 删除、错误 |

## 2. 字阶（全 App 仅此五档，新字号一律就近归档）
- 28dp / 粗体：大标题（首页品牌区）
- 22dp / 粗体：页标题、弹窗标题
- 17dp / 常规：正文、按钮文字
- 15dp / 中等：数字统计、列表主文字
- 13dp / 常规：辅助说明、脚注
- 字体：MiSans 或思源黑体，行距 1.4；任何一屏标题不超过两种字重；中英文不得混排。

## 3. 形状 / 间距 / 阴影
- 圆角：卡片 24dp，弹窗 28dp，按钮与芯片一律全圆 pill，输入框 12dp。
- 间距 8pt 网格：页边距 20，卡片间距 12，卡片内边距 16，图标与文字间距 8。
- 阴影：全 App 仅一级阴影（offset y2 · blur 8 · 黑 8%）；主按钮靠填充色区分不加阴影；
  弹窗可用 y8 · blur 24 · 黑 16%；禁止多重阴影、禁止彩色阴影。

## 4. 图标（重点整改项）
- 全部使用统一的 2px 描边线性图标，24dp 网格、圆头线帽，一个图标库画到底。
- 严禁系统 emoji 占用图标位；文案内的 emoji 可保留作装饰，但不得出现在图标位。
- 图标颜色跟随所在文字色或 colorPrimary，禁用彩色多色图标。

## 5. 背景点阵（品牌元素）
- 亮色模式：3dp 圆点，18dp 网格，颜色 #66EADDFF（即 #EADDFF @40%），
  做成 tile drawable 只铺页面底层。
- 深色模式：3dp 圆点，18dp 网格，颜色 #664A4458，铺 #1C1B22 底。
- 只铺页面底层：不进卡片、不进弹窗内容区、不进图表画布。

## 6. 组件规范
- 主按钮：colorPrimary 填充 pill，白字 17dp/中等，高 52dp。
- 次按钮：colorSurface 底 + colorStroke 描边 pill，colorPrimary 文字。
- 分段控件（如 Preview / Chart / Bead list）：胶囊容器，选中项 colorPrimaryContainer 填充。
- 对话框：与卡片同一语言——colorSurface 底、28dp 圆角、标题 22dp/粗体 配 24dp 线性图标、
  底部按钮 pill 化；禁止直角系统风 AlertDialog；底部按钮必须避让导航栏，不得被屏幕裁切。
- 底部动作区：相关动作必须分组，每组以小标题或分隔线区隔；纯文字 chip 超过 5 个必须分组或图标化。
- 空状态：每页必须设计——像素风小插画（拼豆主题）+ 一句引导文案 + 一个主操作按钮。
- 悬浮层：编辑器画布上禁止常驻按钮遮挡内容；辅助视图一律收进右下角单个 FAB 展开菜单。

## 7. 重点页面修正（存量问题清单，逐条销号）
1. 首页 hero 卡片的灰度相机 emoji → 换线性相机图标。
2. "我的项目 / 库存"等弹窗按第 6 条对话框规范重做；库存 90 色列表顶部加搜索框。
3. 编辑器右侧 3D preview / Play in 3D / AR preview 三个悬浮按钮 → 收进右下角单个 FAB 展开。
4. Bead-along 底部 chips（Locate/Check-in/Focus/How-to/By board/By row/Project/Check/Voice）
   按功能分三组：定位与检查 / 进度与打卡 / 帮助。
5. 知识页：整页文字墙改为步骤卡片，编号做成 24dp 圆形徽标；标题色统一 colorPrimary，
   去掉绿色标题。
6. 全部页面深色模式按第 1、5 条成套适配，逐页检查。

## 8. 首页目标结构（第一张锚点页，先做此页，通过后再铺开）
顶部品牌区（Logo + "Bead your happiness"）→ 主 CTA 大卡片（"开始新图纸"，主紫填充，
内含"从相册选 / 拍照"两个次级按钮）→ "我的项目"横向卡片 → 双列"模板库 / 豆料库存"
→ 底部折叠"实用工具"入口。
要求：首屏不滚动即可见全部主入口；各卡片图标与文字左对齐形成同一条轴线。

## 10. 实施技术注记（v2.60 入库时补充，待用户确认后生效）

以下为落地层面的技术修正与澄清，不改变上文设计意图：

1. **字号单位 dp→sp**：Android 文本用 sp 才会跟随系统字体大小缩放
   （无障碍刚需）。第 2 条五档按 28/22/17/15/13 **sp** 执行。
2. **字体不内置**：内置 MiSans/思源黑体每字重 8~16MB，与包体积红线
   （已含 ONNX 模型）冲突。执行方案 = 系统字体栈（sans-serif，
   中文由各厂商系统字体渲染：MiSans/OriginOS Sans/HarmonyOS Sans），
   视觉零损失、包体零增加。如用户坚持内置再议。
3. **§1 与 §8 的澄清**：§1 写"主 CTA 卡片底 = colorPrimaryContainer"，
   §8 写"主紫填充"。**按 §8 执行**：首页英雄卡 = colorPrimary 实底
   （深色 #D0BCFF 时文字用深紫），卡内两个次级按钮用白/半透明白。
4. **token 迁移映射**（渐进式，随每页改造逐个替换，不做一次性全改）：
   - `bg` → colorBackground；`card` → colorSurface；`subsurface` →
     colorSurface（次级容器场景用 colorPrimaryContainer/colorStroke 酌情）
   - `line`/`inkSoft` → colorStroke；`textMain` → textPrimary；
     `textSub` → textSecondary
   - `danger` → colorDanger；缺豆琥珀 → colorWarning；完成绿 → colorSuccess
   - 旧名在映射完成前保留别名定义，新代码禁止引用旧名。
5. **点阵 tile 规格**：按第 5 条参数重制（18dp 网格 @3x = 54px tile、
   圆点直径 9px），浅/深两套 drawable-nodpi(-night)；圆点颜色带 40% alpha
   直接烘进 PNG。
6. **对话框"底部按钮 pill 化"**：系统 AlertDialog 按钮无法 pill 化，
   涉及的弹窗按第 6 条改为自定义布局对话框（逐个迁移）。
